About LibraVerse

A premier Virtual Library Management System engineered to fuse robust Python database computing with cinematic 3D web presentation.

Flask & Python 3.13

High-performance WSGI routing, secure session authentication, parameterized SQL queries, and modular service-layer separation.

SQLite3 Persistent DB

ACID-compliant relational engine with enforced foreign keys, copy range constraints, atomic transactions, and custom indices.

Pandas & NumPy

DataFrames for inventory aggregation, popularity ranking, time-series monthly trends, and dispersion calculations (mean, std, 90th percentile).

3D Spatial Physics

Hardware-accelerated CSS 3D transforms, perspective depths, simulated book spines, and cursor-follow mouse parallax.

Core System Features

Book Catalog & Deep Search

Case-insensitive multi-field search across titles, authors, categories, and ISBNs with multi-facet category and availability filters.

Automated Circulation Control

Transactional issuance and returns that adjust available inventory atomically, preventing negative stock or over-returns.

Overdue Detection & Fines

Automated due date auditing calculating exact overdue days and fine assessments with dynamic status reconciliation.

Pandas & Excel Reports

Instant generation of UTF-8 CSV exports and multi-tab Excel workbooks powered by Pandas and openpyxl.
